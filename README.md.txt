# Sales Performance Analysis using MySQL

## Project Overview

This project analyzes sales data using MySQL to identify business performance,
customer behavior, product performance, category performance, and city-wise sales.

## Tools Used

- MySQL
- SQL
- MySQL Command Line Client

## Dataset

The dataset contains 10 sales orders with information about:

- Order ID
- Order Date
- Customer Name
- Product
- Category
- Quantity
- Price
- Sales Amount
- City

## Key Business KPIs

- Total Revenue: ₹294,400
- Total Orders: 10
- Total Customers: 10
- Total Units Sold: 24
- Average Order Value: ₹29,440
- Highest Order Value: ₹60,000
- Lowest Order Value: ₹4,000

## Key Insights

1. Laptop generated the highest product revenue at ₹115,000.
2. Keyboard had the highest quantity sold with 7 units.
3. Pune generated the highest city revenue at ₹145,000.
4. January was the best-performing month with ₹111,000 in sales.
5. Electronics generated ₹273,000, representing 92.73% of total revenue.
6. Neha Deshmukh and Pooja Mehta were the top customers with ₹60,000 each.
7. Laptop had a high revenue despite only 2 units being sold.
8. Mouse had the lowest product revenue at ₹4,000.
